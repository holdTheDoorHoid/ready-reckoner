# The packet (superseded)

Since v0.3.0, the printable packet described here has been replaced by two documents: a **binder**,
a during-event reference with ten tabs, a page per person, place and matter, and an airline-style
checklist for every hazard (`PlanOutput.binder`), and a short **Prepare sheet**
(`PlanOutput.prepare_markdown`) carrying the old before-an-event content — the budget, purchase
checklists, decisions and the maintenance calendar. See **[`docs/BINDER.md`](BINDER.md)** for the
document model, what feeds each page, the checklist format, the fit proxy and the goldens; see
`docs/DESIGN.md` §9 for the short overview and `docs/DESIGN-DELTA-v3.md` §4–§6 for the original
specification. This file is kept only so old links (`docs/PACKET.md#...`) still resolve somewhere.
